# 🔐 Password Strength Checker - Chrome Extension

A simple and lightweight Chrome extension to check password strength and estimate how long it might take to crack.  
It analyzes length, uppercase, lowercase, numbers, and special characters, giving real-time feedback.

---

## 🚀 Features
- ✅ Checks password strength (Weak / Strong).  
- ✅ Suggests missing requirements (uppercase, digit, etc.).  
- ✅ Estimates password crack time (seconds → years).  
- ✅ Clean and modern popup UI.  
- ✅ Works completely offline.  

---

## 📦 Installation Guide

### 1. Download Extension Files
Clone or download this repository and place all files in one folder:
- `manifest.json`
- `popup.html`
- `popup.js`
- `icon.png` (your extension logo)

Example folder name: `PasswordCheckerExtension`

---

### 2. Open Chrome Extensions Page
1. Open Google Chrome.  
2. In the address bar, enter:
```

chrome://extensions/

```
3. Press **Enter**.

---

### 3. Enable Developer Mode
- On the top-right corner, toggle **Developer mode**.  
- You will now see: **Load unpacked**, **Pack extension**, and **Update**.

---

### 4. Load the Extension
1. Click **Load unpacked**.  
2. Select the folder where you saved the extension files (`PasswordCheckerExtension`).  

---

### 5. Start Using
- The extension will now appear in your toolbar.  
- Click the **Password Checker icon** to open the popup.  
- Enter a password and instantly see:
- Strength level (Weak/Strong)  
- Suggestions for improvement  
- Estimated crack time
